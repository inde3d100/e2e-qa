# Lessons

The QA agent keeps this file current and reads it first each day. Newest on top. One line for each lesson.

## Traps

Traps of the app and of the journeys: what happened, and what to do next time.

## Answers from the person

The answers to earlier questions, with the date.

## Open questions for the person

The questions that wait for an answer. Ask them again in each summary until the person answers.
