# Changelog

This file lists the changes of each version. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-24

The first public version.

- The `e2e-qa` skill: the app map, the daily round in turns, the triage and the next actions.
- A turn budget in code: 25 turns in the page and 25 through the API each day.
- The memory files: `LESSONS.md`, `BUGS.md`, `turn-log.jsonl`, `COVERAGE.md`.
- The daily start with launchd, cron or GitHub Actions, for Pi, Claude Code and Codex.
- Optional use of REA for apps with no source code.
- A demo app with 5 planted bugs.
