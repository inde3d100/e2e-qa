# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind and direct. Attack problems, not people. To report a problem with the conduct of a person, use [a private report on GitHub](https://github.com/inde3d100/e2e-qa/security/advisories/new).
